# 再開 / 中断

引数: `$ARGUMENTS`

## 引数なし:再開

1. `PROGRESS.md`(中断メモ・チェックリスト・ログ)と `memo.md` の該当フェーズを読む
2. 最近の作業を確認する:`find . -type f -mtime -60 -not -path './node_modules/*' -not -path './.claude/*'` などで更新日時の新しいファイルを見る。中断メモより新しい変更があれば、それも踏まえる
3. 次を簡潔に返す
   - **現在地**:フェーズ、そのフェーズの「作るもの」の進み具合、未合格のチェック項目の数
   - **前回やっていたこと**:中断メモ + 実際のファイルの状態(食い違っていれば指摘)
   - **次の一手**:1 つだけ。学習サイクル(`CLAUDE.md`)のどこにいるかを示し、使うスキルを添える
   - **進め方の再確認**:間が空いていそうなら(中断メモの日付が 2 週間以上前など)学習サイクルを 3 行で振り返る
4. 最後に、前回までの内容から **ウォームアップの問いを 1 つ** 出す(記憶の確認。答えなくても先に進んでよいと伝える)

## `save`:中断

1. この会話でやったこと、本人のコードの状態を確認する
2. `PROGRESS.md` の「中断メモ」を書き換える
   - 最終更新: 今日の日付
   - やっていたこと: 具体的に(「AS の `/token` で PKCE 検証を書いている途中。S256 の比較まで」など)
   - 次の一手: 再開してすぐ着手できる粒度で 1 つ
   - 引っかかっていること / 疑問: 未解決の疑問や、後で `/spec` で引きたいこと
3. チェックリストや「現在のフェーズ」に更新漏れがあれば合わせて直し、ログに 1 行追記する
4. 書いた中断メモを本人に見せて確認してもらう
